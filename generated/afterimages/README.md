# Afterimages OpenSea pack

12 unique 1:1 loops. Site files stay APNG. OpenSea Drop files are GIFs.

Upload every file in `gifs/` (1.gif–12.gif) plus `opensea-metadata.csv`.
OpenSea Drops play GIF, PNG, JPG, and SVG — not APNG.
The CSV uses OpenSea Studio headers: `tokenID`, `name`, `description`, `file_name`, and `attributes[Trait]`.
