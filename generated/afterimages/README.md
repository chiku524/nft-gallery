# Afterimages OpenSea pack

12 unique 1:1 APNG paintings at 640×640, 16 frames, 100ms.

Upload every file in `images/` (1.png–12.png) plus `opensea-metadata.csv` to an OpenSea Drop.
The CSV uses OpenSea Studio headers: `tokenID`, `name`, `description`, `file_name`, and `attributes[Trait]`.
These are finished artworks, not flattened trait stacks.
