# Afterimages OpenSea pack

3,333 unique 1:1 loops at 640×640, 16 frames, 100ms, for an OpenSea Drop on Ink.

Upload every file in `gifs/` (1.gif–3333.gif) plus `opensea-metadata.csv` to an OpenSea Drop.
OpenSea Drops play GIF, not APNG. Tokens 1–50 are the signature APNGs in public/afterimages/.
The rest of the drop is baked as GIFs here. The CSV uses OpenSea Studio headers: `tokenID`, `name`, `description`, `file_name`, and `attributes[Trait]`.
