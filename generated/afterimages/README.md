# Afterimages OpenSea pack

24 unique 1:1 loops at 640×640, 16 frames, 100ms.

Upload every file in `gifs/` (1.gif–24.gif) plus `opensea-metadata.csv` to an OpenSea Drop.
OpenSea Drops play GIF, not APNG. Site previews stay APNG in public/afterimages/.
The CSV uses OpenSea Studio headers: `tokenID`, `name`, `description`, `file_name`, and `attributes[Trait]`.
