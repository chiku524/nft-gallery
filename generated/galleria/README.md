# Galleria On Ink OpenSea pack

50 unique looping paintings at 512×512, 12 frames, 90ms. Each artwork is an open edition.

Create an OpenSea Open Edition collection on Ink. Upload every file in `gifs/` plus `opensea-metadata.csv`. OpenSea plays GIF, not APNG. The site keeps the APNGs in `public/galleria/`.
