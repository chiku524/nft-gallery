# Wicklings OpenSea pack

8,888 flattened lantern loops at 512×512, 12 frames, 80ms.

Upload every file in `gifs/` (1.gif–8888.gif) plus `WICKLINGS-opensea-drop.csv` or `opensea-metadata.csv` to an OpenSea Drop on Arbitrum (chain ID 42161).
OpenSea Drops play GIF, not APNG. APNGs stay in `images/` for the site and restacks.
The CSV uses OpenSea Studio headers: tokenID, name, description, file_name, and attributes[Trait].
Studio trait layers stay in `public/wicklings-traits/` and are not the upload pack.
