# Loopkins OpenSea pack

10,000 flattened loops at 256×256, 12 frames, 80ms.

Upload every file in `gifs/` (1.gif–10000.gif) plus `LOOPKINS-opensea-drop.csv` or `opensea-metadata.csv` to an OpenSea Drop.
OpenSea Drops play GIF, not APNG. APNGs stay in `images/` for the site and restacks.
The CSV uses OpenSea Studio headers: tokenID, name, description, file_name, and attributes[Trait].
