# Party Pandas OpenSea pack

4,444 flattened party-panda loops at 512×512, 12 frames, 80ms.

Upload every file in `gifs/` (1.gif–4444.gif) plus `PARTY-PANDAS-opensea-drop.csv` or `opensea-metadata.csv` to an OpenSea Drop on Base (chain ID 8453).
OpenSea Drops play GIF, not APNG. APNGs stay in `images/` for the site and restacks.
The CSV uses OpenSea Studio headers: tokenID, name, description, file_name, and attributes[Trait].
Studio trait layers stay in `public/party-pandas-traits/` and are not the upload pack.
